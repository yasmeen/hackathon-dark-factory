The assignment

Build a booking site where a table can never be double-booked.

Guests browse restaurants, check a time, book, and cancel. The catch: it has to hold when two people click at the same second, when a request is sent twice, and when restaurants sit in different time zones.

And the app isn't really the entry. The team that built it is.

The hard part

Four things stop a double booking.

  1. One booking at a time. The database locks while a booking is checked and saved.
  2. The database refuses duplicates. One table, one slot, one confirmed booking.
  3. Repeats are recognized. A request sent twice books once.
  4. Only real slots. 7:00 or 7:30, never 7:15, so nothing overlaps quietly.
